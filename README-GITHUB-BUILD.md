# Build NOVA Armor Durability on GitHub

1. Upload the *contents* of this folder to the root of your GitHub repository (not the outer ZIP folder).
2. Open the repository's **Actions** tab.
3. Select **Build NOVA Armor Durability** and press **Run workflow** (or wait for the push build).
4. When the run finishes successfully, open the run and download the `NOVA-Armor-Durability-JAR` artifact.
5. Extract the downloaded artifact ZIP. Put the main `nova-armor-durability-1.0.0.jar` in `.minecraft/mods` alongside Fabric API. Do not install the `-sources.jar` file.

Requires Minecraft Java 1.21.11, Fabric Loader, Fabric API, and Java 21.
